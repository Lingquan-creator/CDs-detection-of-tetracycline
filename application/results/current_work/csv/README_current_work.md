# Current Work Data Index

This folder collects the CSV files and figures used for the latest optimized ln-feature concentration modeling results.

## Key files

- `best_optimized_combinations.csv`: selected input vectors and hyperparameters for Ridge, EXP, and GS.
- `optimization/*_all_trials_ranked.csv`: ranked optimization records for each model and evaluation mode.
- `train/`, `test/`, `loo/`: model predictions, prediction metrics, recovery summaries, heatmap tables, and sample-level recovery records.
- `../fig/current_work/*/model_recovery_heatmap_rsd.png`: recovery mean and RSD heatmaps.
- `model_artifacts/exp_best_*_fit_params.csv`: fitted EXP response parameters for selected configurations.
