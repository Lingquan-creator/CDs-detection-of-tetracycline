1. **出现了“负浓度”**：例如 `0.2` 预测为 `-3.75`，`6.0` 预测为 `-1.97`。这在物理上是不可能的。
2. **小浓度误差极大**：例如 `0.8` 预测为 `3.37`，虽然绝对误差只有 2.5，但**相对误差高达 300%**。
3. **中间震荡**：在 `4.0` -> `6.0` -> `8.0` 的区间内，预测值剧烈波动（7.0 -> -1.9 -> 9.6），说明模型在**过拟合噪声**。

### 根本原因

您目前使用的“线性回归（Ridge）”默认也是为了最小化**均方误差（MSE）**。

* 对于模型来说，把 `100` 预测成 `114`（误差14）比 把 `0.2` 预测成 `-3.7`（误差4）要严重得多（）。
* 因此，模型会牺牲低浓度的准确性，去迎合高浓度的数据。


#### 对数目标变换 (Log-Target Regression) —— **最推荐**

**核心思想**：不要预测 ，而是预测 。
这将迫使模型优化**相对误差**（即它会认为 `0.2`  `0.4` 的错误 和 `20`  `40` 的错误是一样严重的），同时  保证了结果永远非负。

**代码修改示例：**

```python
# 1. 训练阶段：对目标值取对数
# 加上 1e-6 是为了防止 log(0) 报错
y_train_log = np.log(y_train + 1e-6) 

# 训练模型 (依然用 Ridge)
model.fit(X_train, y_train_log)

# 2. 预测阶段：先预测对数，再指数还原
y_pred_log = model.predict(X_test)
y_pred_final = np.exp(y_pred_log) - 1e-6

# 3. 强制非负 (双重保险)
y_pred_final = np.maximum(y_pred_final, 0)

```

**为什么这能解决问题？**

* **消灭负值**： 永远大于 0。
* **均衡权重**：模型会极其重视低浓度的准确度，因为在对数空间里，低浓度的跨度很大。


**修正后的流程：**

1. 特征工程：`log(R)`, `log(G)`, `log(B)`, `R/G`, `G_var`（保持不变）
2. **目标变换**：训练目标改为 `np.log(concentration)`
3. 模型训练：`Ridge(alpha=1.0)`
4. **反向预测**：`concentration = np.exp(prediction)`

这样，您的 `0.2` 样本将得到极好的纠正。
