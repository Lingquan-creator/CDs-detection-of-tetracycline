# 可视化结果说明

本目录包含 `train.py` 训练输出的所有结果文件和可视化图表。

## 📊 图表说明

### 1. 预测值散点图 (`1_prediction_scatter.png`)
- **左图**: 训练集预测性能
- **右图**: LOO交叉验证预测性能
- **内容**: 
  - 散点：预测浓度 vs 真实浓度
  - 误差棒：后验标准差（不确定性）
  - 虚线：理想预测线（y=x）
- **指标**: R²、RMSE、MAE
- **解读**: 点越接近对角线说明预测越准确

### 2. 残差分析图 (`2_residuals_analysis.png`)
- **上排**: 残差 vs 真实浓度
  - 查看残差是否随浓度变化（异方差性）
  - 理想情况：残差均匀分布在0附近
- **下排**: 残差直方图
  - 查看残差分布是否接近正态分布
  - 显示均值和标准差

### 3. 不确定性分析图 (`3_uncertainty_analysis.png`)
- **黑色圆圈**: 真实浓度值
- **红色方块**: 预测浓度均值
- **误差棒**: 90%置信区间
- **解读**: 
  - 误差棒越小说明预测越确定
  - 真实值应该在误差棒范围内

### 4. 后验分布图 (`4_posterior_distributions.png`)
- 展示6个代表性样本的后验概率分布
- **选择**: 低浓度（2个）、中浓度（2个）、高浓度（2个）
- **内容**:
  - 绿色柱状图：概率密度
  - 红色虚线：真实浓度
  - 蓝色实线：后验均值
- **解读**: 分布越窄说明预测越确定

### 5. 原始评估图 (`posterior_evaluation.png`)
- `train.py` 自动生成的评估图
- 包含训练和LOO的预测对比

## 📁 数据文件

### CSV 汇总文件
- `train_posterior_summary.csv`: 训练集预测汇总（23行）
- `loo_posterior_summary.csv`: LOO交叉验证汇总（23行）

**列说明**:
- `conc_true`: 真实浓度（μM）
- `posterior_mean`: 后验均值（预测值）
- `posterior_median`: 后验中位数
- `posterior_mode`: 后验众数（MAP估计）
- `posterior_std`: 后验标准差（不确定性）
- `ci_90_low/high`: 90%置信区间
- `nll`: 负对数似然（越小越好）
- `residual_mean`: 残差
- `abs_error_mean`: 绝对误差

### 概率分布文件
- `train_posterior_probabilities.csv`: 训练集完整概率分布
- `loo_posterior_probabilities.csv`: LOO完整概率分布

**列说明**:
- `filename`: 样本文件名
- `ref_concentration`: 参考浓度值（区间中心）
- `bin_left/right`: 浓度区间左右边界
- `bin_probability`: 该区间的概率密度
- `cdf_right`: 累积分布函数（右边界）

## 📈 性能指标总结

### 训练集
- **R² = 0.9965** （非常优秀）
- **RMSE = 4.23 μM** （误差小）
- **MAE = 2.82 μM** （平均绝对误差）
- **MAPE = 7.99%** （相对误差）

### LOO 交叉验证
- **R² = 0.9734** （优秀）
- **RMSE = 11.71 μM** （泛化误差可接受）
- **MAE = 6.83 μM**
- **MAPE = 48.40%** （低浓度样本拉高了相对误差）

### 不确定性量化
- **平均后验标准差**: ~10.7 μM
- **平均90% CI宽度**: ~35 μM
- 模型能够可靠估计预测不确定性

## 📝 注意事项

1. **LOO MAPE较高的原因**: 
   - 低浓度样本（<1 μM）的相对误差大
   - 例如：真实0.2 μM，预测0.6 μM，绝对误差0.4 μM很小，但相对误差200%

2. **置信区间较宽**:
   - 90% CI平均宽度35 μM是合理的
   - 反映了小样本量（n=23）下的模型不确定性
   - 随着样本增加，CI会收窄

3. **训练 vs LOO性能差距**:
   - 训练集R²=0.9965，LOO R²=0.9734
   - 差距适中，无明显过拟合
   - LOO误差更真实反映泛化能力
