# 拟合结果图

本文件夹包含每个浓度的光谱拟合结果图。

## 文件说明

- 每张图片对应一个浓度的拟合结果
- 命名格式: `fit_<浓度>uM.png`
- 共包含 23 个浓度的拟合图

## 图片内容

每张图包含：
- **黑点**: 实验数据点
- **红线**: 总拟合曲线
- **蓝色/绿色/紫色虚线**: 各个峰的分解曲线
- **灰色点线**: 背景线
- **图例**: 显示各峰的位置 (λ₀)
- **标题**: 显示浓度、R²值和RMSE

## 数据来源

- 原始数据: `data.csv`
- 拟合参数: `results_spec.csv`
- 配置文件: `fit_config.py`
- 生成脚本: `plot_fit_results.py`

## 重新生成

运行以下命令重新生成所有图片：

```bash
python plot_fit_results.py
```
