# ROI 键盘控制快速参考

## 快捷键一览

| 按键 | 功能 |
|------|------|
| **↑ ↓ ← →** / **W S A D** | 精细移动（1像素，默认） |
| **Shift + 方向键** | 粗调移动（水平2px，垂直5px） |
| **Tab** | 切换 ROI ⇄ 背景环模式 |
| **+ / =** | 放大 ROI（+2%） |
| **- / _** | 缩小 ROI（-2%） |
| **Enter / Space** | 确认保存 |
| **Esc / C** | 取消退出 |

## 控制模式

- **ROI 模式** `[ROI]`：控制感兴趣区域位置（默认）
- **背景环模式** `[BG]`：控制背景环位置（Tab切换）

## 背景环设置

背景环支持独立调整水平和垂直方向的内外边距：

- **BG inner H** / **BG outer H**：水平方向内外边距
- **BG inner V** / **BG outer V**：垂直方向内外边距

这样可以创建非正方形的背景环，适应不同形状的ROI。

## 移动控制优化

**默认精细调整**：方向键直接进行1像素级精确移动，适合精细定位。

**粗调模式**：按住 Shift 键使用方向键进行快速移动：
- 垂直方向（↑↓）：5像素/步
- 水平方向（←→）：2像素/步（减小幅度以便更精确控制）

## 使用技巧

1. 直接使用方向键进行精确定位（1像素）
2. 需要快速移动时按住 Shift
3. Tab切换模式后，ROI和背景环可独立移动
4. 使用滑动条独立调整背景环的长宽比
5. 界面右侧面板显示所有参数实时值
