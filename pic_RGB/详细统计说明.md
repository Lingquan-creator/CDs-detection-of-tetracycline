# ROI 详细统计功能说明

## 新增功能

为 `roi_processor.py` 添加了详细的统计信息输出功能，生成 `roi_detailed_statistics.csv` 文件。

## 输出文件

运行批量处理后，会在输出目录生成以下文件：

1. **roi_results.json** - 原有的JSON格式结果
2. **roi_features.csv** - 原有的简化特征CSV
3. **roi_detailed_statistics.csv** - **新增**：详细统计信息CSV
4. **feature_matrix.npy** - 原有的特征矩阵

## roi_detailed_statistics.csv 包含的列

### 文件信息
- `filename` - 图像文件名

### ROI区域统计（样品区域）

#### 每个通道（R, G1, G2, B）的统计量：
- `roi_[通道]_mean` - 均值
- `roi_[通道]_var` - 方差
- `roi_[通道]_std` - 标准差
- `roi_[通道]_median` - 中位数
- `roi_[通道]_p10` - 10%分位数
- `roi_[通道]_p50` - 50%分位数（中位数）
- `roi_[通道]_p90` - 90%分位数
- `roi_[通道]_saturation_ratio` - 饱和比例（接近白电平的像素占比）

#### 通道比值（抗整体亮度漂移）：
- `roi_R_G_ratio` - R/G 比值
- `roi_B_G_ratio` - B/G 比值
- `roi_R_B_ratio` - R/B 比值
- `roi_G1_G2_ratio` - G1/G2 比值

### 背景区域统计（bg_前缀）

所有上述统计量都有对应的背景版本，前缀为 `bg_` 而非 `roi_`：
- `bg_[通道]_mean`
- `bg_[通道]_var`
- `bg_[通道]_std`
- ... (其他统计量同上)

## 统计量说明

### 1. 均值、方差、分位数
- **均值 (mean)**: 平均像素值
- **方差 (var)**: 像素值的离散程度
- **标准差 (std)**: 方差的平方根
- **分位数 (p10/p50/p90)**: 
  - p10: 10%的像素值小于此值
  - p50: 中位数
  - p90: 90%的像素值小于此值

### 2. 饱和比例 (saturation_ratio)
- 定义：接近白电平（95%白电平阈值）的像素占比
- 用途：作为图像质量/过曝异常的提示
- 正常值：应接近0
- 异常值：>0.05 表示可能过曝

### 3. 通道比值
- **R/G, B/G**: 相对于绿色通道的比值
- **R/B**: 红蓝比值
- **G1/G2**: 两个绿色通道的比值（应接近1）
- **用途**: 抗整体亮度漂移，提供相对颜色信息

## 使用示例

### 运行批量处理
```bash
python roi_processor.py
```

### 或运行测试脚本
```bash
python test_detailed_stats.py
```

### 读取CSV进行分析
```python
import pandas as pd

# 读取详细统计
df = pd.read_csv('roi_results/roi_detailed_statistics.csv')

# 查看ROI区域的R通道均值
print(df['roi_R_mean'])

# 查看饱和比例
print(df[['filename', 'roi_R_saturation_ratio', 'roi_G1_saturation_ratio', 
          'roi_G2_saturation_ratio', 'roi_B_saturation_ratio']])

# 查看通道比值
print(df[['filename', 'roi_R_G_ratio', 'roi_B_G_ratio']])

# 检查质量：查找过曝图像
saturated = df[df['roi_R_saturation_ratio'] > 0.05]
print(f"可能过曝的图像: {len(saturated)}")
```

## 质量控制建议

基于新增的统计信息，可以进行以下质量控制：

1. **检查饱和比例**
   ```python
   # 任何通道饱和比例 > 5% 视为异常
   quality_check = df[
       (df['roi_R_saturation_ratio'] > 0.05) |
       (df['roi_G1_saturation_ratio'] > 0.05) |
       (df['roi_G2_saturation_ratio'] > 0.05) |
       (df['roi_B_saturation_ratio'] > 0.05)
   ]
   ```

2. **检查G1/G2一致性**
   ```python
   # G1/G2 比值应接近1
   g_ratio_check = df[
       (df['roi_G1_G2_ratio'] < 0.8) | 
       (df['roi_G1_G2_ratio'] > 1.2)
   ]
   ```

3. **使用分位数检测离群点**
   ```python
   # 使用p10-p90范围检测异常分布
   df['roi_R_range'] = df['roi_R_p90'] - df['roi_R_p10']
   ```

## 技术细节

### 饱和阈值计算
```python
saturation_threshold = white_level * 0.95  # 95%白电平
```

### 通道比值计算
```python
epsilon = 1e-6  # 防止除零
G_mean = (G1_mean + G2_mean) / 2.0
R_G_ratio = R_mean / (G_mean + epsilon)
```

## 注意事项

1. 白电平 (white_level) 从RAW文件元数据中读取，默认为16383（14-bit）
2. 所有比值计算都添加了小的 epsilon 值以防止除零
3. 详细统计功能会重新加载图像，可能需要一些额外时间
4. CSV文件使用6位小数精度保存浮点数
