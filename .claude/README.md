# Claude Code Configuration

This directory contains configuration for Claude Code to use when working with this repository.

## Model Configuration

The repository is configured to use **Claude Sonnet 4.5** (`claude-sonnet-4-5-20250929`) for AI-assisted development tasks.

### Configuration File

- **File**: `.claude/config.json`
- **Model**: Claude Sonnet 4.5
- **Model ID**: `claude-sonnet-4-5-20250929`

## About This Repository

This repository focuses on carbon dots (CDs) detection of tetracycline using traditional machine learning methods:

- Ridge regression for concentration prediction
- Exponential fitting models
- Amortized variational posterior estimation with PyTorch

The Claude Sonnet 4.5 model can assist with:
- Code review and refactoring
- Documentation improvements
- Bug fixes and feature implementations
- Analysis of machine learning pipelines
- Data processing optimization

## Usage

When using Claude Code with this repository, the Sonnet 4.5 model will be automatically used based on this configuration.
