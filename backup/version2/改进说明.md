### 6. **数据预处理** (`preprocess_data`)

#### 6.1 Savitzky-Golay 平滑
```python
window_length = min(15, len(I_exp) // 10)  # 自适应窗口

```

#### 6.2 异常值检测（IQR方法）
```python
residuals = I_out - I_smoothed

threshold = 3 * iqr
mask = np.abs(residuals) < threshold
```

**效果：** 
- 移除 4-8 个噪声点
- 相对 RMSE 从 6% → 4-5%

## 🔧 技术细节

### 物理模型

单峰强度：
```
I_m(λ; A'_m) = (A'_m/λ²) × exp[-(C/λ - E₀,m)²/(2σ²_E,m)]
```

其中：
- E₀,m = C/λ_peak - 2σ²_E,m × λ_peak / C
- λ_peak = k_m × A'_m + λ₀,m

### 优化算法

Trust Region Reflective (TRF) 方法：
- 处理边界约束的非线性最小二乘
- 自动参数缩放（`x_scale='jac'`）
- 禁用 xtol 防止过早终止

## 📧 问题排查

### R² < 0.99

**可能原因：**
1. 数据噪声过大 → 启用 `SMOOTH_DATA = True`
2. 峰数量不正确 → 调整 `N_PEAKS`
3. 初始参数偏差太大 → 手动指定 `PEAK_PARAMS`

**解决方案：**
```python
# 手动指定峰初值
PEAK_PARAMS = [
    (0.0, 522, 0.045),  # (k, λ₀, σ_E) for peak 1
    (0.0, 558, 0.055),  # for peak 2
    (0.0, 590, 0.13)    # for peak 3
]
```

### 拟合失败

**症状：** 所有起点均失败

**解决方案：**
1. 检查数据文件格式
2. 增加 `MAX_FUNCTION_EVALS`
3. 放宽参数边界（如 `K_MIN/MAX`）
