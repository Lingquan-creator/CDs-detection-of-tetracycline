# 参数可视化使用说明

## 📊 新增功能

### 1. fit_spectrum_general.py 更新

**新增输出：** CSV文件中现在包含 `Peak{i}_max_intensity` 列

```
Peak1_max_intensity  # 峰1的最大强度值（不含背景）
Peak2_max_intensity  # 峰2的最大强度值
...
```

**计算公式：**
```
I_max = A' / λ₀²
```

---

### 2. plot_parameters.py - 参数可视化脚本

**功能：** 自动读取 `fit_results_batch.csv` 并绘制所有拟合参数随浓度变化的图

**生成的图片：**

1. `A_prime_vs_concentration.png` - 振幅参数 A'
2. `k_vs_concentration.png` - 位置-强度斜率 k
3. `lambda0_nm_vs_concentration.png` - 中心波长 λ₀
4. `sigma_E_eV_vs_concentration.png` - 能量展宽 σₑ
5. `peak_position_nm_vs_concentration.png` - 峰位置 λₚₑₐₖ
6. `E0_eV_vs_concentration.png` - 中心能量 E₀
7. **`max_intensity_vs_concentration.png`** - ⭐ 峰最大强度 (新增)
8. `integrated_intensity_vs_concentration.png` - 积分强度
9. `summary_plot.png` - 汇总图（4个关键参数）

---

## 🚀 使用方法

### 步骤1: 运行拟合程序

```bash
python fit_spectrum_general.py
```

**输出：** `fit_results_batch.csv` (包含所有拟合参数)

---

### 步骤2: 运行可视化脚本

```bash
python plot_parameters.py
```

**输出：** `parameter_plots/` 文件夹（包含9张图片）

---

## 📈 图表说明

### 每张图的特点

- **横坐标：** 浓度 (μM)
- **纵坐标：** 对应的拟合参数
- **每条曲线：** 代表一个峰
  - 🔵 实心圆 (o) - Peak 1
  - 🟠 方块 (□) - Peak 2  
  - 🟢 三角形 (△) - Peak 3
  - 🔴 菱形 (◇) - Peak 4

### 示例分析

#### `max_intensity_vs_concentration.png`

预期趋势：
- **Peak 1-3**: 强度随浓度增加而降低（荧光淬灭）
- **Peak 4**: 可能在高浓度出现（聚集态发光）

#### `lambda0_nm_vs_concentration.png`

观察是否有红移或蓝移：
- 红移 → 量子点聚集/尺寸增大
- 蓝移 → 量子限域效应增强

## ⚙️ 自定义配置

编辑 `plot_parameters.py` 顶部的配置：

```python
# 输入输出设置
INPUT_CSV = "fit_results_batch.csv"  # 输入文件
OUTPUT_DIR = "parameter_plots"        # 输出目录
DPI = 150                             # 图片分辨率 (150-300)
FIGSIZE = (10, 6)                     # 图片尺寸

# 选择要绘制的参数
PARAMETERS = [
    'A_prime',
    'k',
    'lambda0_nm',
    'sigma_E_eV',
    'peak_position_nm',
    'E0_eV',
    'max_intensity',           # ⭐ 新增
    'integrated_intensity',
]
```

---

## 📊 数据处理

### 浓度识别

脚本自动识别以下格式：
- `"Blank"` → 0 μM
- `"0.05μM"` → 0.05 μM
- `"12μM"` → 12 μM
- `"240μM"` → 240 μM

### 数据排序

自动按浓度从低到高排序，确保曲线连续。

## 🎨 峰样式自定义

修改 `PEAK_STYLES` 列表更改颜色和标记：

```python
PEAK_STYLES = [
    {'color': '#1f77b4', 'marker': 'o', 'label': 'Peak 1'},  # 蓝色圆圈
    {'color': '#ff7f0e', 'marker': 's', 'label': 'Peak 2'},  # 橙色方块
    {'color': '#2ca02c', 'marker': '^', 'label': 'Peak 3'},  # 绿色三角
    {'color': '#d62728', 'marker': 'D', 'label': 'Peak 4'},  # 红色菱形
]
```

**可用标记：**
- `'o'` - 圆圈
- `'s'` - 方块
- `'^'` - 上三角
- `'v'` - 下三角
- `'D'` - 菱形
- `'p'` - 五边形
- `'*'` - 星形

## 💡 高级用法

### 只绘制特定参数

编辑 `PARAMETERS` 列表：

```python
# 只绘制强度相关的参数
PARAMETERS = [
    'max_intensity',
    'integrated_intensity',
]
```

### 调整图片质量

```python
DPI = 300         # 高分辨率（用于发表）

```

### 修改汇总图

编辑 `create_summary_plot` 函数中的 `key_params`：

```python
# 选择最关键的4个参数
key_params = [
    'lambda0_nm',           # 峰位置
    'max_intensity',        # 最大强度
    'integrated_intensity', # 积分强度
    'sigma_E_eV'           # 展宽
]
```

## 🔍 故障排查

### 问题1: "文件不存在"

**解决方案：**
1. 确保先运行 `fit_spectrum_general.py`
2. 检查 `fit_results_batch.csv` 是否在当前目录
3. 修改 `INPUT_CSV` 路径

### 问题2: 某些峰没有显示

**可能原因：**
- 该峰的数据包含 NaN 或无效值
- 峰编号超出范围

**解决方案：**
检查 CSV 文件中的数据完整性。

### 问题3: 图片质量不佳

**解决方案：**
```python
DPI = 300  # 提高分辨率
```
